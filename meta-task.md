Build a functionality where a user can input one or multiple website page URLs and automatically extract the meta title and meta description for each URL.

Requirements:

Provide an option to create/select a folder to store the results.
Include a form field where users can enter URLs (single or multiple).
On submission, fetch the metadata from each URL.
Generate and download a CSV file containing:
Website URL
Meta Title
Meta Description
Ensure proper handling of invalid or unreachable URLs.
The output CSV should be clean, structured, and ready for SEO use.
